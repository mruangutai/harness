### Stage 2: Discuss Phase

**Command:** `/gsd-discuss-phase [sub-phase-A-number]`

**What to decide during discuss:**
- Confidence scoring algorithm: how is confidence calculated from field extraction results?
- Schema: what fields does the confidence record need (score, per-field scores, timestamp, status)?
- Routing: what triggers the human review queue? (answer: score < 0.90 per D-02)
- Data blocking: how is blocked data represented? (status field, flag field, separate table?)
- Queue implementation: API endpoint shape for fetching the human review queue
- Binary threshold rationale: confirm no 70-90% tier (per D-02)

**Scope creep to catch:** If annotation UI, PDF viewer, or annotation form comes up during discuss — push it to Sub-Phase B. This must appear in the `<deferred>` section of the resulting CONTEXT.md.

**Evidence checkpoint after discuss:**
```bash

```
