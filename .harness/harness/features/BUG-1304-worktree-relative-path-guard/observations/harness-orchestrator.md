- 2026-09-05: BUG-1304 — the fail-closed/fail-open boundary for an unreadable claim registry was NOT settleable from the BRIEF text. REQ-05 enumerates three fail-closed causes (unparseable JSON, non-object payload, unsupported schema) and a directory at the registry path is none of them, which is the reading I put to the Advisor; the binding ruling went the other way — keep `except (OSError, UnicodeError) -> UnreadableRegistry` in `live_claims` and update FEAT-51 `_feat51_fail_open_cases` (tests/integration/test-check-domain.py:3953) from fail-open to fail-closed. Lesson: an enumeration in a requirement is not automatically exhaustive, and a plan that files the OSError asymmetry as a follow-up (#1342) does not thereby settle which side of the line OSError sits on TODAY. Cost: one cycle (12 of 13) plus a held task.
- 2026-09-05: BUG-1304 — reading a source file while the main session is mid-edit returned coherent-looking but FABRICATED content: `read :raw` and a piped `grep -A45` both showed a `message += ...` block that `grep -rn` could not find anywhere in the tree seconds later. It was the pre-edit version spliced with the post-edit one. Any premise check against a file another agent is actively editing must be taken from `git show <sha>:<path>`, never from the working tree.
- 2026-09-05: BUG-1304 — a plan task whose `verify:` runs `check-state.sh` CANNOT pass during build. INV-26 asks `gh_board.project` where each card belongs and it places a sub-issue at its own task station verbatim, so a `done` task wants the done column, which nothing writes before `ship`; check-state D-24 widens the accepted set only while the FEATURE station is `review`. So the whole-tree checker task has to be sequenced AFTER the review station write, not as the last build task the plan graph implies. Cost: one wasted verify attempt and a premature `done` I had to be ready to revert.
- 2026-09-05: BUG-1304 — the pin ordering is a two-commit dance, not one write. Pinning `review_sha` before committing the feature-station change makes INV-6 report the pin STALE ("plan.yaml has changed since it was pinned"). Working order: commit plan.yaml station alone, pin to THAT sha, commit feature.json separately. Pinning to the merge commit instead trips it immediately.
- 2026-09-05: BUG-1304 — a task `verify:` that regenerates and diffs a GENERATED artifact is blind to caps asserted only in the unit suite, because the generator preserves hand-written fields rather than deriving them. DEC-218 passed T-07 verbatim and failed `test_committed_index_is_complete_and_within_budget` on a 33-word ruling against a 30-word cap.
