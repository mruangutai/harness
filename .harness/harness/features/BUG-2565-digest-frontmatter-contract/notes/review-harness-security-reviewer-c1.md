## Findings

- **Substance · med · must fix · T-02** — `.omp/extensions/harness-hooks.ts:107–115,430–439,1859–1867`. If a validator process returns zero without having validated and its reply is empty or malformed, the hook allows the object without an unavailable notice, including without the validator's semantic/record checks. The pinned classifier returned `blocked=false, unavailable=absent` for both responses; the base did too, but retained strict provider shape checking. The script path is module-relative (`:31–38`) and not supplied by the child. Interpreter choice still uses inherited PATH (`:496–508`; `validate-digest.py:1`), so integrity depends on the host environment and checkout. A child-only path change was not demonstrated. **Repair:** require an explicit, versioned approval emitted only after all governed checks finish, and treat missing/malformed evidence as unavailable only for yield. Preserve deny precedence and the other broad gates' behavior. Validator-side protocol edits in `validate-digest.py:3041–3045` are a **scope change** (not in T-02's `files:`); approve that companion change and cover empty/malformed zero exits separately from valid approval.
- **Form · med · T-01/T-06** — `notes/research-yield-refusal-probe.md:17,117–129`; `.harness/harness/docs/BUILD.md:60–62`, `.harness/README.md:184–187`. The receipt does not prove that the payload never reaches the parent in any form, as D-03's unqualified wording suggests. **Repair:** distinguish accepted structured data from untrusted failure prose in the probe and docs; have the operator confirm that distinction for D-03. This is not evidence of a structured digest bypass. Suppressing failure prose itself would be a scope change.
- **Substance · low · T-02** — `.omp/extensions/harness-hooks.ts:398–404,432–435,880–885`.
