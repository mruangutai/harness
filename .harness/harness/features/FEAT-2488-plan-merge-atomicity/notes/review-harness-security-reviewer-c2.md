## Residual findings

- **A1 · substance · med · T-01 · Spoofing/Tampering.** Already present at `987e57b9`. A party who can introduce a sidecar, but not write the protected pair directly, can cause an authorized write to replay arbitrary bytes into the pair. The before hash tests current state, not writer identity; both the after image and its checksum come from the journal. Replay precedes the requesting transform and does not call schema or approval checks (`harness_merge.py:272–311,404–429,484–492`; `feature_json_write.py:225–227`). No remote or journal-only placement route was demonstrated; journal files are not ignored by the pinned `.gitignore`.
- **A2 · substance · med · T-01 · Tampering/DoS.** `harness_merge.py:314–342` checks the pathname, not the opened descriptor. `O_NOFOLLOW` closes the final-leaf symlink swap and `O_NONBLOCK` removes the ordinary FIFO-open wait, but there is no `fstat` for type or identity before reading. A local actor able to replace directory entries concurrently can still change what object is read, or switch parent identity between checking, replay and unlink (`:404–460`). Stable directory aliases are controlled by the caller, not by journal fields; the plan and ledger entry points resolve their explicit paths first. Stable hard-linked member names are replaced, not written through; a hard-linked journal can be read but unlink removes only its recovery pathname. None of these makes the payload choose another destination by itself.
- **A3 · substance · low · T-01 · Tampering.** Already present at `987e57b9`. Discovery's case-sensitive suffix filter (`harness_merge.py:390–401`) can miss a differently cased suffix that the filesystem resolves as the canonical journal. A pair write can replace that existing entry instead of examining or refusing it (`:522,559–573`). Case-insensitive lookup was measured in the temp filesystem; the journal consequence is from source inspection. This needs a noncanonical local entry, not one emitted by the producer.
- **A4 · substance · low · T-01 · Diagnostic injection.** Already present at `987e57b9`. An actor who can create a differently named entry ending in the journal suffix can place control bytes in its basename; refusal renders the discovered pathname verbatim (`harness_merge.py:251–259,390–401,441–450`). This does not work through JSON field values in a canonical journal. Filename lengths are filesystem-bounded, but the 80-character limit does not touch them.

**Availability boundary.** A malformed journal still deliberately refuses directory writers; a diverged valid journal refuses its members. Reading/decoding a regular sidecar is unbounded, even during lock-free discovery. Lock ordering is by fixed pathnames, not inode identity; lock aliases need separate filesystem changes, and ordinary flock contention is timed. These are not new capabilities of the fix delta.
