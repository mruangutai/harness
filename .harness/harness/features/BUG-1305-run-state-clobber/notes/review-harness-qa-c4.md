every case, mutated or not. Fix: export `PYTHONPATH=<worktree's real bin dir>` alongside
`CHECK_DOMAIN_BIN` so the heredoc's own `sys.path.insert` (pointing at the copy's directory)
still resolves `harness_boundary` from the fallback PYTHONPATH entry. Verified against an
unmutated byte-identical copy at `/tmp` before trusting any mutant result (exit 2, correct
message, only once PYTHONPATH was added — exit 0/empty stderr without it).
