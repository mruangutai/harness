# Observations - harness-security-reviewer

- 2026-09-07: BUG-240 factory_workspace.py identity guard (`os.path.realpath(path) == os.path.realpath(_control_plane_root())`) is defeated by a case-only path spelling difference on a case-insensitive filesystem (macOS APFS default): confirmed `os.path.samefile()` returns True for two differently-cased paths while `os.path.realpath()` returns two different strings for them, then reproduced end-to-end against the real guard — both the identity and dirty checks pass silently and `fetch`+`checkout`+`reset --hard` execute against what is, on disk, the control-plane checkout, switching it off an in-progress branch. Any identity check meant to hold on macOS/APFS needs `os.path.samefile` (when both paths exist), not `realpath` string equality — filed as review must_fix, not yet fixed as of ed047fde.
