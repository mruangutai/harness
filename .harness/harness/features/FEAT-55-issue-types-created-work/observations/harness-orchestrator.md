- 2026-09-04: FEAT-55 plan seam. `check-domain.sh`'s handoff gate calls `handoff_done_when.problems(rel, content, root)` with `rel` worktree-STRIPPED but `root` resolved from the script's own bin dir — the MAIN checkout. For a feature whose dir exists only in a linked worktree, every legal authority type (`plan-task:`, `brief-sc:`, `approval:`) is unresolvable, so `notes/handoff-plan.md` cannot be written at all. Measured all three, then measured two forms that DO pass: an `approval:` pointer spelled through the checkout (`.claude/worktrees/<repo>/<FEAT>/.harness/...`), and the plain pointer when root IS the worktree. Used the first. Same root-vs-worktree class as the #749 feature-schema note at check-domain.sh:1374.

- 2026-09-05: FEAT-55 build.
