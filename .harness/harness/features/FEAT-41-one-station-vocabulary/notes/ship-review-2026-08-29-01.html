B-1bugShell pathname expansion is non-POSIX. In a clean dir holding only a/f.txt, echo */f.txt prints a/f.txt b/f.txt, and echo */nomatch.txt prints both members instead of the literal pattern — the shell substitutes phantom paths that do not exist. So grep -rn PAT dir/*/f.yaml errors ENOENT on each phantom and exits 2 even when it finds matches, making grep … ; test $? -eq 1 unusable harness-wide. Measured twice: minimal probe, and the real tree (31 of 40 dirs held the file, 56 matches found, still exit 2).
