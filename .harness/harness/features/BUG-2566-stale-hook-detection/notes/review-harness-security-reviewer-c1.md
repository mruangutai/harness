# Security review — BUG-2566, cycle 1

**FAIL — the detector can silently trust the wrong startup baseline.** Reviewed `87efcd8a..8e18c053f60369b38c182ecbbea75ccc0002947e`. In scope: hook enforcement, filesystem reads, refused-call output, and matching tests/SPEC. Other changed paths are feature planning, configuration of this review, and run records, not new runtime surfaces. Static source/data-flow audit; no live host or race reproduction.

1. **Substance · med · must fix · T-01 — baseline is not bound to executed source** (`.omp/extensions/harness-hooks.ts:68–91,100–111`). If a checkout update replaces the file after OMP reads the old source but before module evaluation takes its baseline, the old hook records the new file's digest. Every later governed call sees the new digest and silently runs the old policy. If the startup read instead records `absent`, `not-a-file`, or `unreadable:*`, equality with the same non-content state also permits governed calls indefinitely. A concurrent checkout update is enough; no persona tool access is needed. This defeats the BRIEF's loaded-code guarantee. **Repair:** use a digest of the exact source handed to the loader (or a loader-enforced stable snapshot for both reads), and refuse governed calls when the baseline is unverifiable; retain Main recovery and the validated BLOCKED yield. Add startup-boundary coverage for source replacement and missing baseline. Loader integration, if needed, requires explicit scope approval. T-02's claim at `.harness/harness/docs/SPEC.md:799–805` depends on that fix.
2. **Substance · low · advisory · T-01 — unbounded whole-file read can stall the process** (`.omp/extensions/harness-hooks.ts:70–75,1799–1806`). A local writer able to replace the hook path can leave an oversized regular file there, directly or behind a symlink. The next governed call synchronously reads the whole file into memory before it can refuse; a long stall or memory exhaustion also takes out Main's unaffected recovery calls. No persona write access to that path was established. **Repair:** bound memory and keep the disk read off the event loop; on a read deadline or resource failure, refuse instead of accepting a partial hash.

**Other boundaries.** BLOCKED yield requires a persona and a top-level non-array object (direct or JSON-decoded) with the exact verdict; missing, nested-only, malformed, and nonmatching variants do not qualify. The exempt call still reaches `validate-digest.py --hook` (`harness-hooks.ts:114–124,1796–1799,1939–1967`); the validator checks live children and the contract before settling the claim. Main's Bash paths use the same stateless prefilter and command conversion (`:33,1640–1642,1796–1797,1817`), so no command caught by the existing merge gate escapes the stale predicate. Static non-regular entries are not opened; `O_NONBLOCK` and `fstat` on the same descriptor prevent a substituted FIFO from blocking the read. The FIFO test (`tests/unit/omp-hooks.test.ts:4506–4521`) covers a FIFO already present at `stat`, not the `stat`/open interleaving. Refusal text exposes only an ISO timestamp and a fixed checkout-relative module path, not raw filesystem errors, symlink targets, or the absolute checkout path (`harness-hooks.ts:46–48,89–107`).
