## SEC-01 — substance · med · T-01 · must fix

If a recorded, non-kept run has an unreadable directory inside `ui/`, dry-run can report a successful prune preview; a real prune can delete an earlier readable UI lane and then fail inside `rmtree` without the pre-mutation list of unreadable paths. A local writer with control over the affected lane's permissions, or accidental permissions damage, suffices; no remote actor or privilege escalation is established. This is a static control-flow conclusion. The skip is inherited from `47d6c54d`'s staging walker, but approved SC-02 and the new assertions in `harness-ship.md:51–53` and `DECISIONS.md:8159–8161` explicitly cover **every unreadable directory under a recorded run**. The chmod fixture exercises only `qa/` (`test-prune-run-evidence.py:303–332`). Main should make the preflight and its tests cover unreadable recorded UI directories in both modes, with no mutation even when another lane is eligible for deletion, while preserving link skips and UI-only deletion (DEC-174/179).
