- **T-01 · substance · low — physical diagnostic lines can be forged.** At `:779–781`, the script path and every dynamic command argument pass through `shlex.quote`; the Inspect, ambiguous and persona-mismatch command sites use the helper (`:784–809,:826–838`). A render-only probe with spaces, apostrophes, `;`, `$()` and newlines recovered the exact original argv through POSIX-style tokenization; the full command keeps those characters as data. But `shlex.quote` preserves literal LF. The same command rendered as nine physical lines and an inert fixture marker appeared on standalone lines, also in the actual refusal stderr. Someone who can alter a stored feature or arrange a checkout path can make a line look like a separate instruction; that could mislead an operator who reads or copies only that line. No ordinary child-task input path or automatic execution was established; the hook still exits 2. For line-sensitive values, render a visible escaped diagnostic and withhold the copy-ready command rather than silently changing its argv.
