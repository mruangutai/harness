# Send-back criteria — distill-pm (written before the return)

pm is sent back only if:
- a candidate gets neither an applied op nor a stated rejection reason;
- an applied op is not reflected in the receipt or in the resulting file (receipt path missing);
- an entry names a FEAT/T-/issue id, exceeds 50 words, or is not WHEN/DO;
- an add lands in a capped section (craft Patterns 15/15, Gotchas 15/15, Outcomes 10/10) without displacing a named survivor;
- `expertise_update` items lack `persona: harness-pm` or carry `state`.

Not grounds for send-back: rejecting every candidate; choosing which survivor to displace (O-03).
