# Cycle 1 security review — FEAT-2458

**FAIL — T-02 does not confine the new unlink to the main checkout’s `.harness` directory.** The filename cannot inject a Git option or shell command, but checking the leaf for a symlink does not protect the parent path.

**Scope and evidence.** Reviewed `322b12b0..9b5b6a7a05c3dc8aa382699e33477d2f0397281c` with `git diff --numstat`, `git show`, and `git ls-tree` at the pin. In scope: T-01 `worktree_terminal.py` (local filename → landed Git objects) and T-02 `post-merge-sweep.py` (main checkout → unlink and operator output). The T-02 registry and JSON inventory each remove only the entry for the retired helper; the replacement uses the same fleet lookup (`worktree_terminal.py:111–140`). `test-check-plan-routes.py` changes a docstring; `test-worktree-terminal.py` and `test-post-merge-sweep.py` add fixture coverage, not production entry points. The five other changed paths are feature records and handoff notes, not changes to the hook’s trust rules. No new credential, dependency, network, or authorization surface.

| Kind / severity / task | Finding |
|---|---|
| Substance / med / T-02 — must fix | **Parent-symlink escape (STRIDE T/E).** `post-merge-sweep.py:348–371` lists `.harness` by pathname and later re-resolves that pathname for `os.remove`. An operator who has redirected `.harness` to another checkout’s metadata directory can lose that checkout’s regular stamp for a feature terminal in the main checkout, even if the other checkout still uses the mark. A local actor with write access to the checkout’s parent entry but not the destination directory can also cause the hook account to perform the unlink if that account has destination write access. The pinned Git object is a tree (`040000`), so an ordinary checkout is not a symlink; the precondition is local substitution or relocation, not a stamp name or ordinary merge. The leaf check cannot reject a substituted parent, including a swap during classification. Open the actual `.harness` directory without following a symlink, then use the same directory descriptor for listing, checking, and unlinking. Verify that a symlinked `.harness` leaves the outside stamp intact. |
| Substance / low / T-02 — advisory | **Diagnostic spoofing (STRIDE S/R).** An actor who can create a stamp-shaped file in `.harness` can include a newline or terminal control in the basename. The unresolved branch interpolates the raw basename and reason (`post-merge-sweep.py:361–364`; `worktree_terminal.py:630–634`), letting that actor forge a removal-looking line in the operator’s output without removing a stamp. Escape controls in emitted names and reasons while keeping the signed per-stamp reporting. No automated authorization consumer was identified in the changed path. |

Git is invoked without a shell (`worktree_terminal.py:52–57, 182–221`). A final-component symlink is skipped; a later leaf swap to a symlink cannot redirect unlink to its target. Output shows names and classification/error context (an OS error can include a local path), not stamp contents or Git blob bodies. SC-08 public surface is explicit at `worktree_terminal.py:7–13`.
