## Newly found in the changed text

- **Substance · med — Invalid stream encodings are accepted as captured bytes.** `plan.yaml:339–341,360`; SC-05/06. The new validation checks string type, but permissive `base64.b64decode` ignores non-alphabet characters. For a valid CLI or replay ID, `stderr: "!!!!"` on one side and `stderr: ""` on the other both decode to empty, so no `stderr` divergence is required. The key check closes the omitted-key case, but does not enforce the new base64 contract. Reject malformed encodings before comparison.
- **Substance · med — A source-only disclosure can attribute the wrong source to a ruled item.** `plan.yaml:341,372,376`; SC-08 and D-02 (`BRIEF.md:47,98–102`; `plan.yaml:152`). For a real `d02#1:unreached` ID, substituting `file: wrong.py`, `symbol: wrong`, `old_source: x`, `new_source: y` still passes: the new check tests only that the four labels have nonblank values. That contradicts the intent to read the exact source templates from both refs and can give the operator the wrong basis for a ruling. Bind those fields to the expected file, symbol and templates at baseline and pin.
- **Substance · med — The new measured-block format can pass without the `divergence:` records SC-08 requires in `build-divergences.md`.** `plan.yaml:335,341,376,378`; `BRIEF.md:47`. A file with only valid `divergence_entry:` blocks passes, including for `audit:stdout`; the literal `divergence:` line is checked in the generated receipt, a different file. Preserve that required marker in `build-divergences.md` and verify it against the same IDs. The reversible bytes repr itself meets the exact-byte requirement; `bd==E` binds complete measured bodies, and source-only entries are not presented as captured output.

No use-before-definition: `n` and `gb` are defined at `:327–328` (the latter first called after `R` is set), `t` at `:330`, `dv` at `:335`, and `nz`, `ki` and `D` at `:339` before their uses at `:340–346`. No other new breakage found in the routed text. D-02 authorization and the bun-leg rulings stay with the operator.
