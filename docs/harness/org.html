The harness org

Sixteen agents in four tiers. Work is delegated downward one layer at a time; every return travels upward as a digest. State passes by file path, never by conversation.

Members have no spawn tool — the platform withholds it at the last permitted layer, so members are leaves by construction, not by convention. CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH is "3", which is what pins these four tiers. Models are pinned per role: the judgment tier — orchestrator, the three leads, pm, visual-designer, documentor — runs opus; the other members run sonnet. Flows are FEAT-NN-<slug>, defects BUG-NN-<slug>, and every dispatch title carries the flow id all the way down, so the spawn tree reads as one chain.

How work and answers travel

Down — delegation

  1. You open a flow at the main session.
  2. It spawns an orchestrator for that feature.
  3. The orchestrator hands a team run to one lead.
  4. The lead dispatches its members — independent steps in a single turn, so they run at once.
  5. Each member gets a goal, input paths, and the output paths it must write. Never pasted content.

Up — digests

  1. Members report a digest to their lead.
  2. The lead collates and assesses — including sending work back for rework.
  3. It reports one team digest up.
  4. The orchestrator assesses across teams, routes questions between leads, delegates another cycle.
  5. Only what needs you — escalations, briefings, approvals — reaches the main session.

The digest — one contract at every tier

VERDICT: PASS | FAIL | BLOCKED | ESCALATE
DIGEST:
  headline:       one line, conclusion first
  files_touched:  [ ... ]        doers only
  open_questions: [ ... ]        non-empty routes upward, toward you
  expertise_update: [ ... ]      [] except under a distillation dispatch
artifact: path to the real output — the pointer, not the payload

Every field is required, and each persona adds its own on top of these three universals (qa carries suite and matrix_ok, doers carry task) — say “nothing” with an explicit [], never by leaving the key out. A lead's team digest is the same shape plus a per-member roll-up, written to <run>/digest.md. validate-digest.py enforces this as a SubagentStop hook — one of the eight platform prerequisites settings.json must carry — seven hooks across four events, plus the spawn-depth cap — so a malformed return is rejected at source and the agent must fix it before it can finish. Not advisory: a reader normalizes drift charitably and then one routing decision quietly goes the wrong way.

Four rules that hold it together

Paths, not payloadsA return is control flow. The artifact is a file and the next step is told where it is. Pasting content forward burns the context budget the org exists to protect.
One writer per pathEvery domain is declared in team-config.yaml. An agent reaching outside its own paths is blocked and told which are its own. Scope, honestly: Write and Edit are governed before the fact and the common shell shapes by a sibling guard, but arbitrary shell is not winnable and is caught after. The main session is never governed — it has to be able to record your decisions.
Shape is not permissionWho may write a file and how long it may be are separate questions, and conflating them cost four write routes once. State files and CLAUDE.md carry line budgets bound on every route — refused before a Write, reported after an Edit or a shell command, and binding on the main session, which authorization deliberately is not.
Cycles bound the workRetry cycles are a hard cap — exhausting them stops the branch, preserves the work, and brings you the decision.
